# Проект по автоматизации API тестирования

## Описание проекта

Это проект по автоматизированному тестированию RESTful API сервисов. Основная цель проекта — проверить взаимодействие с двумя различными API: Rick and Morty API для получения информации о персонажах и эпизодах, и Reqres API для тестирования операций с пользователями (создание, удаление). Проект использует фреймворк Cucumber для написания тестов и Allure Report для генерации отчетов.

## Тестируемые API

*   **Rick and Morty API:** [https://rickandmortyapi.com/](https://rickandmortyapi.com/)
*   **Reqres API:** [https://reqres.in/](https://reqres.in/)

## Покрытая функциональность

Проект включает автоматизированные тесты, покрывающие следующие сценарии:

*   **Rick and Morty API:**
    *   Поиск и получение информации о конкретном персонаже (например, Морти).
    *   Получение данных о последнем эпизоде, в котором участвовал персонаж.
    *   Получение информации о последнем персонаже, появившемся в этом эпизоде.
    *   Проверка соответствия расы персонажей.
    *   Проверка отличия локаций персонажей.
*   **Reqres API:**
    *   Создание нового пользователя с заданными данными.
    *   Проверка успешного создания пользователя (статус код, данные ответа).
    *   Удаление существующего пользователя.
    *   Проверка успешного удаления пользователя.
    *   Проверка отсутствия пользователя после удаления.

## Отчеты Allure

После выполнения тестов будут сгенерированы отчеты Allure.

### Генерация отчета

Для генерации отчета используйте команду:

```bash
mvn allure:report
```

### Просмотр отчета

Для просмотра сгенерированного отчета в браузере выполните:

```bash
mvn allure:serve
```
