# Проект по автоматизации тестирования

Проект содержит набор автоматизированных тестов интерфейса EduJira. Тесты предназначены для проверки функциональности Jira.

## Функционал

Проект включает тесты, покрывающие следующие сценарии:

*   Проверка успешной авторизации
*   Проверка успешного перехода на страницу проекта 'TEST'.
*   Поиск существующей задачи, проверка статуса, версии для задачи.
*   Создание бага и увеличения счетчика задач.
*   Перевод бага через основные статусы жизненного цикла ("В РАБОТЕ", "ГОТОВО").

## Технологический стек

Проект разработан с использованием следующего стека технологий и инструментов:

*   Java 17
*   JUnit 5
*   Selenide
*   Maven
*   Allure


## Структура проекта
```markdown

├── src/
│ ├── main/
│ │ └── java/
│ │ ├── pages/ # Классы взаимодействия с элементами
│ │ └── util/ # Класс для настроек проекта
│ └── test/
│ ├── java/
│ │ ├── tests/ # Тестовые сценарии, проверяющие функциональность
│ │ └── webHooks/ # Содержат общие действия перед/после тестов
│ └── resources/ # Конфигурация с настройками для тестов, конфигурация Allure
├── .gitignore
└── pom.xml
```

## Запуск тестов

```bash
mvn clean test
```

## Отчеты Allure

После выполнения тестов будут сгенерированы отчеты Allure.

### Генерация отчета

Для генерации отчета используйте команду:

```bash
mvn allure:report
```

### Просмотр отчета

Для просмотра сгенерированного отчета в браузере выполните:

```bash
mvn allure:serve
```
